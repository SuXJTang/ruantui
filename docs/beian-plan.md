# 备案 + 国内 CDN 迁移评估

> 目标：让国内用户稳定、快速地访问 luoluo.fun
> 评估日期：2026-11-10

---

## 一、先纠正我之前的一个错误

**我之前说「`.fun` 域名无法备案」—— 这是错的。**

查证结果：
- 青云备案文档的北京管局支持后缀列表里**明确包含 `.fun`**
  （来源：https://docsv4.qingcloud.com/user_guide/site/record/intro/limit/）
- 多个备案服务商的「可备案后缀」列表里也有 `.fun`

**结论：现有域名 `luoluo.fun` 可以直接备案，不需要买新域名。**

前提是两点：
1. 域名在**国内注册商**实名认证过（若在境外注册需要先转入）
2. 注册局已通过工信部审批（`.fun` 已通过）

## 二、备案要求（个人主体）

### 材料清单

| 材料 | 说明 |
|---|---|
| 身份证 | 正反面清晰扫描件 |
| 手机号 | 本人实名，需接收核验短信 |
| 邮箱 | 常用邮箱 |
| 服务器 | 国内云服务商的备案授权码 |
| 核验照 | 部分服务商要求幕布拍照或 App 人脸识别 |

### 硬性条件

- **必须有境内服务器**（阿里云/腾讯云等），备案是绑在服务器上的
- 一个个人主体最多备案 **3 个网站**
- 网站名称不能含「博客」「论坛」「在线」「社区」等词
- 个人备案不能涉及经营行为

### 时间

```
服务商初审    1-3 个工作日
管局终审      10-20 个工作日

合计          约 2-4 周
```

## 三、关键问题：数据怎么办？

这是评估里最重要的一点。

### 现状

```
静态资源（HTML/CSS/JS/图标）  →  Cloudflare
数据库 + 认证（Supabase）      →  境外
```

### 备案后能解决什么、不能解决什么

| 部分 | 备案 + 国内 CDN 后 | 效果 |
|---|---|---|
| **页面加载** | ✅ 走国内 CDN | 0.03-0.1 秒，稳定 |
| **工具列表** | ✅ 已内嵌在 HTML 里 | 跟着 CDN 走，一样快 |
| **搜索/筛选** | ✅ 前端本地完成 | 不依赖网络 |
| **点下载** | ✅ 直接外链 | 不依赖你的服务器 |
| **登录/注册** | ❌ 仍走 Supabase | 还是境外，仍会抖 |
| **收藏同步** | ❌ 仍走 Supabase | 同样受影响 |
| **浏览量统计** | ❌ 同样 | 可以有损 |

**核心判断：备案后，最影响体验的「看工具列表」会变得非常快，
但「登录/收藏」这些需要数据库的功能依旧是老样子。**

不过这些是低频操作，且已有重试 + 降级机制兜底，
实际影响比现在小得多。

## 五、技术迁移方案

### 架构变化

```
现在：
  用户 → Cloudflare → Worker → Supabase
                      ↘ 静态资源

迁移后：
  用户 → 国内 CDN（静态资源，秒开）
          ↘ Cloudflare Worker（/sb API 代理，可选保留）
                ↘ Supabase
```

### 具体步骤

**阶段 1：备案**
1. 确认域名在国内注册商（如已实名，直接购买服务器即可）
2. 买一台最低配国内服务器（备案用，不跑业务）
3. 提交备案

**阶段 2：配置 CDN**
1. 注册又拍云/七牛云，添加 `luoluo.fun` 为加速域名
2. 源站指向 Cloudflare 的 IP 或者直接上传静态文件
3. 配置 HTTPS 证书
4. DNS 把 `luoluo.fun` 的 CNAME 改到 CDN

**阶段 3：验证**
1. 国内访问速度测试
2. 确认 `/sb` API 代理仍然正常
3. 确认登录/收藏不受影响

### 代码改动量

**几乎为零。** 静态站点部署到 CDN 不需要改代码。

可能需要的调整：
- 如果 CDN 不支持某些 header，需要调整 Worker 的缓存策略
- 确认 SSR 内容能正确缓存（现在已经是短缓存策略）

## 六、备案的风险与注意事项

### 必须遵守的

1. **网站内容合规**：不能有违法违规内容
2. **底部展示备案号**：需链接到 `https://beian.miit.gov.cn`
3. **公安备案**：ICP 备案通过后 30 天内需做公安备案
4. **信息真实**：管局可能电话核验，需保持手机畅通

### 可能被驳回的情况

| 情况 | 说明 |
|---|---|
| 网站名称含「博客/论坛/在线/社区」 | 个人备案禁止 |
| 网站内容涉及经营 | 需企业备案 |
| 服务器地域与户籍不符 | 部分省份要求 |
| 域名未实名或境外注册 | 需先处理 |

### 你的站需要特别注意

当前站名「软推 - 精选软件工具推荐」有**推荐下载**属性。
备案时网站内容描述建议写：

> 个人技术分享，收集整理常用软件工具的官网地址，供学习参考。

**避免**写「软件下载」「资源分享」这类可能触发审核的词。

## 八、我的建议

### 建议做，但分步

**第一步：先买服务器 + 提交备案**（成本 60-100 元，1 天操作）

备案审核期间网站照常运行，不影响现在。

**第二步：备案下来后配 CDN**（半天）

这是收益最大的一步，页面加载会快一个数量级。

**第三步：观察一段时间**

如果登录/收藏的抖动仍然影响体验，再考虑数据库也迁国内
（那是另一个量级的工作，可以缓）。

### 不做的风险

只要继续托管在 Cloudflare 免费版，国内访问就会一直「时好时坏」。
用户会流失，SEO 也会受影响（百度对访问不稳定的站降权）。
