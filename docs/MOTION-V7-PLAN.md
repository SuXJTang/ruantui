# 动效升级路线 v7（在 v6 基础上）

> 制定：2026-11-21
> v6 已上线：分类分布条 · 数字滚动 · 卡片视口入场 · 点击涟漪 · 顶栏收缩 · Hero 视差 · 详情热度条
> 本文只列「下一步还值得做」的，并明确写出**不做什么**。

---

## 一、评估标准

一条动效进不进这轮，看三条：

1. **有信息量吗** —— 只解释「发生了什么」的动画可以留，纯装饰的不加
2. **会不会打断任务** —— 覆盖在内容上、延迟可点击时间的一律否决
3. **能不能降级** —— 必须能在 `prefers-reduced-motion` 和触屏下分别降级

---

## 二、P0：体验缺口（不是锦上添花）

### 2.1 骨架屏 → 内容过渡
**现状**：数据请求期间首屏是空的，加载完成后 45 张卡一次性出现（虽然有入场动画，但那时页面已经"跳"了一下）。
**做法**：
- 网格区先渲染 6 个 `.skeleton-card`（样式已有，`skShimmer` 也在）
- 数据到达后骨架淡出（150ms）、卡片依次入场
- 失败时骨架换成现有的 `.data-error` 块，不要停在骨架态

**验收**：4G 模拟下从白屏到有内容之间不出现「空白网格」。

### 2.2 详情面板分段入场
**现状**：940px 的宽面板一次性弹出，视觉上"砰"一下。
**做法**：打开后 40ms 间隔依次淡入 `header → 操作卡 → 信息卡 → 二维码`（CSS `animation-delay`，总计 200ms 内结束）。
**注意**：不要给左栏正文加入场，那会推迟阅读。

### 2.3 Service Worker 新版本提示条
**现状**：每次发版，用户第一眼是旧界面，要再刷一次。
**做法**：`sw.js` 的 `updatefound` 事件里，检测到新 worker 就显示一条底部提示「有新版本，点击刷新」，点击执行 `location.reload()`。
**价值**：不是动效，但它解决了「我们改了用户看不到」这个反复出现的问题。

## 三、P1：增强已有动效

### 3.1 筛选切换的 FLIP 重排
**现状**：点分类 → 整个网格重渲染 → 卡片重新播入场，位置是"跳"过去的。
**做法**：用 First-Last-Invert-Play：重排前记录每张卡的位置，重排后用 `transform` 从旧位置过渡到新位置（180ms）。
**风险**：卡片数变化大时（45 → 1）需要处理"消失的卡"（直接淡出，不参与 FLIP）。
**优先级理由**：这是目前交互中唯一还显得"生硬"的地方。

### 3.2 顶部滚动进度条升级
现在是一条纯色 2px 条。改成「渐变填充 + 末端一个小光点」，光点在到达 100% 时脉冲一次。
成本极低，属于细节打磨。

### 3.3 卡片图标的轻微视差
鼠标在卡片上移动时，图标沿鼠标方向反向偏移 ≤3px（已有 `--mx/--my`，复用即可）。
**注意**：只对 `pointer: fine` 生效，且位移要小于卡片自身的 hover 上浮。

### 3.4 主题切换用 View Transitions
现在切主题是整页重绘 + 一层 radial 波纹。改用 `document.startViewTransition()`，让新主题从点击的色点上圆形扩散覆盖。
**降级**：不支持该 API 的浏览器保留现有波纹。

## 四、P2：探索（做之前先小范围验证）

| 想法 | 价值 | 风险 |
|---|---|---|
| 卡片 → 详情面板的图标「飞入」 | 强，视觉记忆点 | 需要 View Transitions + 元素命名，Safari 支持晚；弹窗结构复杂，容易做出「卡顿的飞入」 |
| 搜索结果关键字脉冲高亮 | 中 | 容易变成"满屏闪"，且已有静态高亮 |
| Hero 背景分层视差（文字 / 光斑 / 网格三层不同速度） | 中 | 移动端必须关，桌面收益有限，和现有单层视差重叠 |
| 列表滚动时的"透视"（上下卡片微缩放） | 低 | 明显增加合成开销，45 张卡上会掉帧 |

---

## 五、明确不做

- **全屏粒子 / 3D 背景**：现有星空粒子已经够，再加会抢内容
- **自动播放的轮播 / 跑马灯**：工具站没有需要"轮流展示"的内容
- **每个元素都加动画**：动效密度一高，页面就从"精致"变成"廉价"
- **自定义鼠标光标 / 拖尾**：会干扰点击判断
- **骨架屏上再加 shimmer + 脉冲 + 位移**：一种就够

---

## 六、实施顺序与验收

```
P0-1 骨架屏      →  P0-3 更新提示条  →  P0-2 面板分段入场
      ↓
P1-1 FLIP 重排   →  P1-4 View Transition  →  P1-2 进度条  →  P1-3 图标视差
```

统一验收：

- [ ] 首屏 LCP 不低于 v6（当前 FCP 696ms / DCL 772ms）
- [ ] 动效时长全部 ≤ 400ms，无一超过 1s
- [ ] `prefers-reduced-motion: reduce` 下所有位移/缩放关闭，仅保留 ≤100ms 的透明度变化
- [ ] 触屏（`pointer: coarse`）下不出现 hover-only 的动效
- [ ] 45 张卡连续滚动时 DevTools Performance 无长任务 >50ms
- [ ] 弹窗 / 菜单等浮层的动画不影响其可点击时间（不设 `pointer-events: none` 等待）
