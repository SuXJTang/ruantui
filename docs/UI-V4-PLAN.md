> 制定日期：2026-11-21
> 目标版本：v4.0.0（`style.css` 重构 + 卡片/顶栏/Hero 改版）
> 现状基线：`?v=86` / `CACHE_VERSION v94`，45 款工具，10 个分类
> 约束：必须遵守 `AGENTS.md` 全部铁律；本次**只改表现层**，不动数据流、鉴权、Supabase、Worker

## 二、设计方向：Aurora（极光精工）

一句话：**从「深灰卡片列表」升级为「有光源、有层次、有质感的精选橱窗」。**

三条原则：

1. **光源一致** — 全站只认一个主色光（`--brand`），所有发光/渐变/选中态都由它派生，
   避免现在"五色圆点 + 橙主色 + 蓝色 accent 混用"的杂乱。
2. **层次靠表面不靠描边** — 用 4 级表面（page / card / raised / overlay）+ 柔和阴影
   拉开距离，描边只做收敛（`rgba(255,255,255,.06)` 级）。
3. **动效克制** — 只有 4 种：hover 上浮、焦点光晕、列表交错淡入、骨架 shimmer。
   全部包在 `prefers-reduced-motion` 里。

### 2.1 表面与色彩 token（重写 `:root`）

```css
/* 亮色 */
--s0:#F6F7FA;  /* 页面底 */
--s1:#FFFFFF;  /* 卡片 */
--s2:#F1F3F8;  /* 输入框、次级块 */
--s3:#FFFFFF;  /* 弹窗（不透明，铁律 2.2） */
--line:rgba(17,24,39,.08);
--line-2:rgba(17,24,39,.14);
--ink1:#0F1524; --ink2:#4A5468; --ink3:#8A93A6;

/* 暗色 */
--s0:#0A0D14; --s1:#12161F; --s2:#1A1F2B; --s3:#1E2431;
--line:rgba(255,255,255,.07); --line-2:rgba(255,255,255,.13);
--ink1:#E8ECF4; --ink2:#9AA4B8; --ink3:#69738A;

/* 品牌 */
--brand:#FF7D20; --brand-2:#FF4D6D;   /* 渐变对 */
--ok:#22C55E; --warn:#F59E0B; --danger:#EF4444; --vip:#F5B942;
```

保留现有 5 个主题切换（`data-theme="ocean/aurora/forest/crimson"`），
但只覆盖 `--brand` / `--brand-2` / `--brand-rgb` 三个变量，其余全部自动派生。

### 2.2 排版与间距

- 字号阶梯：`11 / 12.5 / 14 / 16 / 20 / 26 / 34`（rem 化不必做，保持 px 便于对齐）
- 行高：正文 1.6，标题 1.25
- 间距基数 4px：`--sp-1:4 --sp-2:8 --sp-3:12 --sp-4:16 --sp-5:24 --sp-6:32 --sp-7:48`
- 圆角：`--r-sm:10 --r-md:14 --r-lg:20 --r-xl:28 --r-full:999px`

## 三、组件级改造清单

### A. 顶栏（`.topbar`）
- 玻璃背景 `color-mix` + `backdrop-filter: blur(20px) saturate(180%)`
- 搜索框：胶囊、内嵌图标、聚焦时外圈 `--brand` 光晕 + 描边变亮；右侧显示 `⌘K` 提示
- 右侧动作区收敛：主题 5 色点改为**一个调色盘按钮 + 弹出面板**（减少 4 个常驻元素）
- 账号入口不变（铁律 8.1：`.topbar-right` 保持 `margin-left:auto`）

### B. Hero（`.profile`）
- 结构升级：标题（渐变色文字）+ 副标题 + 统计胶囊组（工具数 / 分类数 / 总下载）
- 背景：两层径向极光 + 细网格（`background-image` 纯 CSS，无图片请求）
- 头像加 `--brand` 光环，loading 骨架

### C. 筛选与排序（`.filter-row`）
- 单行横向滚动（`overflow-x:auto` + 隐藏滚动条 + 两端渐隐遮罩），不再折两行
- 每个 chip = 图标 + 文案 + 计数徽标；选中态为 `--brand` 渐变填充 + 内发光
- 分类映射图标表（JS 小改动，见 F）

### D. 工具卡片（`.tool-card`）★ 核心
- 结构不变（不改 `ui.js` 的 DOM），仅 CSS + 一个鼠标跟随变量
- `display:flex; flex-direction:column` → `.tool-actions { margin-top:auto }` 解决底部参差
- hover：`translateY(-4px)` + 描边转 `--brand` 30% + 外发光，`transition .28s cubic-bezier(.2,.8,.2,1)`
- 鼠标跟随光斑：`background: radial-gradient(320px circle at var(--mx) var(--my), rgba(var(--brand-rgb),.12), transparent 65%)`
- 图标：64px、圆角 18、内阴影 + 顶部高光；hover 时轻微放大
- 标签：超过 3 个折叠为 `+N`
- VIP 卡：金色细边角标

### E. 按钮体系
- `.tool-visit-btn`（主）：`--brand → --brand-2` 横向渐变 + hover 流光扫过（uiverse 风格，纯 CSS `::after` 斜切位移）
- `.tool-visit-alt`（次）：透明底 + `--line-2` 描边，hover 填充 `--s2`
- `.tool-visit-locked`：虚线描边 + 锁图标，`--ink3`
- `.form-submit` / `.mgmt-add-btn` 统一到同一套（主/次/危险）

### F. 骨架屏与加载
- 首屏 `#pageLoader` 保留（防白屏），但改为「logo + 进度光带」
- 新增 `.tool-card.skeleton` shimmer 骨架（数据加载期间显示 6 个）
- 公告/通知面板加载态同套 shimmer

### G. 弹窗（详情 / 管理 / 表单）
- 统一 `.modal`：`--s3` 实色、`--r-xl`、`box-shadow` 三段式、顶部 1px 高光
- 遮罩：`rgba(6,8,14,.62)` + `backdrop-filter: blur(6px)`
- 详情顶部改为「大图标 + 标题 + 元信息行」，下半部分卡片化分段（介绍 / 说明 / 标签）
- 关闭按钮固定右上，命中区 ≥ 40px

### H. 微交互
- 卡片入场：交错淡入（保留 `animationDelay`，改为 40ms 步长、位移 12px）
- 收藏心形：点击缩放回弹 + 小红点波纹
- Toast：圆角 16、左侧状态色条
- 主题切换：`View Transitions API`（支持则用，否则退化为现有 ripple）

## 四、技术方案（为什么这样做）

| 决策 | 选择 | 理由 |
|---|---|---|
| `style.css` 重写 or 覆盖 | **重写**（全新 4 段结构） | 现文件 1056 行注释已乱码，覆盖式会越堆越乱 |
| 类名是否改 | **全部保留**（285 个类名一个不改） | 不改 JS 模板 = 零功能回归风险 |
| 新增 CSS 文件？ | **不加**，仍单一 `style.css` | 无构建步骤，多文件只会多一次请求和版本号 |
| 新 JS 依赖 | **零**。鼠标光斑用 12 行原生事件委托 | 铁律：不引入 npm/构建 |
| Tailwind 类组件 | **不采用** | uiverse 里 438 个 Tailwind 组件全部排除 |
| 图标 | 现有 FontAwesome 6.4 + 自托管 SVG | 不新增 CDN |

### 4.1 类名守恒验证（阶段 0 产物）

从旧 `style.css` 提取全部选择器 → `docs/ui-v4-selectors.txt`（543 条 / 285 类）。
新文件写完后逐条比对：

```
旧文件有、新文件无 → 必须逐条确认是「有意删除」还是「漏了」
新文件有、旧文件无 → 只允许出现 v4 新增类
```

脚本：`scripts/css-audit.js`（阶段 0 编写，纯 Node，无依赖）

### 4.2 从 uiverse.io 取用的轮子（MIT，已在文件内标注作者）

已 clone `uiverse-io/galaxy`（3529 个组件）到本地，筛出 2897 个纯 CSS 组件，
逐类目看过后**只取 4 个微交互**，其余布局自研（uiverse 的整卡多是装饰性玩具，不适合产品站）：

| 用途 | 来源组件 | 改造方式 |
|---|---|---|
| 主按钮流光 | `Buttons/LonelyCY05_sneaky-snake-25.html` | 取 `::after` 斜向光带 + hover 位移，配色改 token |
| 搜索框胶囊 | `Inputs/thsrnsm_calm-cat-15.html` | 取胶囊 + 内嵌圆形图标按钮结构 |
| 边框光晕 hover | `Cards/andrew-demchenk0_perfect-crab-47.html` | 取 `inset` 光晕 + 渐变描边思路 |
| 开关 / Toggle | `Toggle-switches/` 高分组件 | 用于主题面板内开关（如「跟随系统」） |

> 归属：文件内保留 `/* From Uiverse.io by <作者> — MIT */` 注释。
